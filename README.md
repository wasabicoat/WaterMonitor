# เฝ้าระวังระดับน้ำ เจ้าพระยา (Chao Phraya Water Monitor) 🌊

แดชบอร์ดเฝ้าระวังระดับน้ำและศูนย์รวมกล้อง CCTV ริมแม่น้ำเจ้าพระยาแบบเรียลไทม์ (ครอบคลุมพื้นที่ นนทบุรี, ปากเกร็ด, ปทุมธานี และลุ่มน้ำเจ้าพระยา)

---

## ✨ ฟีเจอร์หลัก (Features)

1. **กล้องสดและภาพถ่ายทอดสด (Live Streams & Cameras)**
   - สตรีมภาพสดกล้องท่าน้ำนนทบุรี (MediaMTX / HLS)
   - สตรีมภาพสดกล้องท่าน้ำเทศบาลเมืองปทุมธานี
   - วิดีโอถ่ายทอดสด Facebook Live จากหน่วยงานท้องถิ่น
   - ตารางกล้อง CCTV เทศบาลนครนนทบุรี (>30 กล้อง) แยกตามโซนประตูระบายน้ำและจุดเสี่ยง พร้อมระบบ Lightbox ดูภาพขยายขนาดใหญ่

2. **ข้อมูลระดับน้ำและการแจ้งเตือน (Water Levels & Alerts)**
   - ระดับน้ำสถานีท่าน้ำปากเกร็ด (ม.รทก.) พร้อมมาตรวัดระดับเตือนภัย (ปกติ / เฝ้าระวัง / วิกฤต)
   - ข้อมูลปริมาณน้ำไหลผ่าน (ลบ.ม./วินาที) ที่สถานี C.2 นครสวรรค์ และเขื่อนเจ้าพระยา (C.13)
   - กราฟระดับน้ำย้อนหลัง 24 ชั่วโมง (Chart.js)
   - ตารางสถานะสถานีวัดระดับน้ำเทศบาลนครนนทบุรี 41 สถานี (ระดับน้ำหน้า/ท้ายประตู, ระดับน้ำผิวถนน, ปริมาณฝนสะสม)

3. **ดีไซน์และการแสดงผล (Responsive UI)**
   - รองรับการแสดงผลทั้งบน Desktop และ Mobile
   - รองรับโหมดมืดอัตโนมัติ (Dark Mode / Light Mode)
   - Sticky Section Navigation ช่วยให้ข้ามไปยังส่วนต่างๆ ได้อย่างรวดเร็ว

## 🚀 ข้อกำหนดและการติดตั้ง (Requirements & Setup)

โปรเจกต์นี้มี Backend เป็น **PHP** สำหรับทำ API Proxy และแคชข้อมูลเพื่อลดภาระเซิร์ฟเวอร์ต้นทางและเลี่ยงปัญหา CORS:

- **PHP 7.0+ หรือ PHP 8.x**
- Extensions ที่จำเป็น:
  - `curl`
  - `openssl`
  - `json`
- สิทธิ์ในการเขียนไฟล์ (Write permission) สำหรับโฟลเดอร์ `cache/`

### การรันบน Local / Web Server
วางโฟลเดอร์โปรเจกต์ใน Web Root ของ Web Server (เช่น Apache, Nginx หรือ Synology Web Station) หรือรันผ่าน PHP Built-in Server:

```bash
php -S 0.0.0.0:8000
```
เปิดบราวเซอร์ที่ `http://localhost:8000`
